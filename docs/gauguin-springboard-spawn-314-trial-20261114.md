# 0314 无人值守真机方案：验证 SpringBoard 子进程加载修正

0313 已完成并独立恢复。它确认 SpringBoard 的观测库在进程身份检查处
被拒绝，因此触摸是否到达 SpringBoard、主循环是否阻塞仍未观测到。

并增加调用方和启动标志日志。目标程序、观测库和 mobile 身份限制保留。
这是定位约五秒绘图间隔所需的观测修正，尚非已验证的 60fps 修复。

0313 的一次性授权已执行完。0314 尚未获写入或启动授权；全程无需用户
在电脑或手机旁操作。
