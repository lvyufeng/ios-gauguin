# 0315 无人值守真机方案：定位主线程的同步等待

0314 已证明触摸能够进入 SpringBoard，同时主线程出现约四至五秒停顿。
四次 CA 观测区间的结束与 C4 绘图任务创建相差不到 0.5 ms，具体等待函数
仍未知。本轮在同一内核和 GPU 行为下，增加有界主线程调用栈采样。
本轮是定位试验，尚非已验证的 60fps 修复。全程无需用户在现场。
